# Java Placement Training

A collection of beginner-friendly Java programs for placement preparation and core programming practice.

## Topics Covered

- Data types and type conversion
- Variables and operators
- Conditional statements
- Loops and switch statements
- Arithmetic and logical problems
- Grading and eligibility examples
- Object-oriented examples with classes and objects

## Project Structure

The repository contains standalone Java source files. Example programs include:

- `Hello.java` – a basic Java program
- `DataTypes.java` – primitive data types
- `arithmetic_operators.java` – arithmetic operations
- `assignment_operators.java` – assignment operations
- `logical_opeators.java` – logical operations
- `if_else.java` – conditional statements
- `for_loop.java` – loop examples
- `switch_case.java` – switch-case statement
- `Student.java` and `Student_2.java` – basic class examples

## Prerequisites

- Java Development Kit (JDK) 8 or later
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or VS Code

Verify your Java installation:

```bash
java -version
javac -version
```

## How to Run

Compile and run a program from the repository root:

```bash
javac Hello.java
java Hello
```

For a file containing a `main` method, replace `Hello.java` and `Hello` with the required file and class name.

This repository is useful for practicing:
